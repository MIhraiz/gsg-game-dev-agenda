# GSG Game Development Agenda

The topic map and lecture-by-lecture agenda for GSG's Track A: Game Development 2026 course.

**Website:** https://mihraiz.github.io/gsg-game-dev-agenda/

`index.html` is the standalone published page. GitHub Pages serves the root of the `main` branch; `.nojekyll` disables Jekyll processing.

The page is maintained in a separate study workspace as `agenda/track-a-agenda.html` and copied here for publication. In that workspace, run `python tools/publish.py --push` to copy, commit and push the current agenda. Edit the maintained source before publishing an update.
